# ClipFarm Privacy Policy

_Last updated: November 18, 2026_

ClipFarm is a personal tool run by the owner of this repository to publish short clips to the owner's own YouTube channel.

**What it accesses.** With the channel owner's permission (Google OAuth), ClipFarm uses the YouTube Data API to upload videos to the owner's channel and to look up public channel information. It does not access anyone else's account.

**What it stores.** Clip files, titles, descriptions and public video/channel IDs are stored in the owner's private Supabase database. OAuth credentials are stored as encrypted GitHub Actions secrets. No personal data about viewers or other users is collected, sold or shared.

**Third parties.** Data is processed by Google/YouTube, Supabase, GitHub and Netlify only as needed to run the tool. ClipFarm's use of YouTube data follows the [YouTube API Services Terms of Service](https://www.youtube.com/t/terms) and the [Google Privacy Policy](https://policies.google.com/privacy).

**Revoking access.** The channel owner can revoke ClipFarm's access at any time at <https://myaccount.google.com/permissions>.

**Contact.** Open an issue on this repository.
